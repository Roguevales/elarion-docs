# Recommended Discord Bots

Find useful Discord bots for moderation, security, support, leveling, server utilities, and community games. Choose tools that fit your server's needs without adding unnecessary complexity.

{% hint style="info" %}
**Before you invite a bot:** Review its permissions, check its current feature set, and only grant the access it actually needs.
{% endhint %}

## Moderation & Security

Protect your community, manage member behavior, and keep server activity under control.

* [**Sapphire**](https://sapph.xyz/) — Moderation commands, AutoMod, logging, role management, and server utilities.
* [**Wick**](https://wick.bot/) — Anti-raid and anti-nuke protection, verification, and automated security filters.
* [**Beemo**](https://beemo.gg/) — Anti-raid protection designed to detect and block coordinated raids and suspicious activity.

## Tickets & Support

Organize support requests and give members a structured way to contact your staff team.

* [**Tickety**](https://tickety.top/) — Ticket panels, private support channels, transcripts, and support management.
* [**Ticket Tool**](https://tickettool.xyz/) — Customizable ticket panels, private support tickets, and ticket management.

## Leveling & Engagement

Encourage participation through activity rewards, experience points, and community features.

* [**Lurkr**](https://lurkr.gg/) — Activity-based leveling, rank cards, XP settings, and role rewards.
* [**Arcane**](https://arcane.bot/) — Message and voice leveling, leaderboards, role rewards, and activity features.
* [**Arclo**](https://arclo.gg/) — Server management and community features. Check its current modules for available tools.

## Server Utilities

Add specialized features that make your server more interactive and easier to manage.

* [**Countr**](https://countr.xyz/) — Counting channels and community counting activities.

## Economy & Games

Give members optional activities, virtual currencies, and games to enjoy together.

* [**UnbelievaBoat**](https://unbelievaboat.com/) — Virtual economies, currency systems, shops, income commands, leaderboards, and games.
* [**Grow a Tree**](https://growatree.app/) — A collaborative tree-growing game built around community participation and progression.

{% hint style="warning" %}
**Setup tip:** Start with one primary moderation bot, then add specialized tools only when you need them. Overlapping configurations can cause conflicting moderation actions, duplicate logs, or confusing permissions.
{% endhint %}
