# Server Design Resources

Explore custom emojis, versatile symbols, and striking graphics to give your server a unique identity and a polished appearance.

{% hint style="info" %}
**Quick tip:** Pick a small, consistent visual style before adding assets. Matching colors, icon styles, and emoji choices make a server easier to scan.
{% endhint %}

## Emoji Collections

Find emojis to personalize channel names, roles, announcements, and messages.

* [**Discadia Emojis**](https://discadia.com/emojis/) — Browse emoji collections.
* [**Emoji.gg**](https://emoji.gg/) — Discover emojis for your server.
* [**DiscordMojis**](https://discordmojis.com/) — Explore Discord emoji collections.

## Symbols & Unicode

Use your device's built-in emoji or character panel to quickly insert symbols.

* **Windows:** Press `Win + .` to open the emoji panel.
* **macOS:** Press `Control + Command + Space` to open the Character Viewer. On supported devices, you can also use the Globe or Fn key.

### More emoji and symbol tools

* [**GetEmoji**](https://getemoji.com/) — Copy and paste emojis.
* [**Picsart Emoji Tools**](https://tools.picsart.com/text/emojis/) — Explore emoji and text tools.
* [**Twemoji Cheat Sheet**](https://twemoji-cheatsheet.vercel.app/) — Browse emoji references.

## Graphics & Server Art

Find graphics to customize your server's appearance, from profile pictures to banners and animated designs.

* [**Creavite**](https://auto.creavite.co/) — Create animated graphics, profile banners, avatar decorations, and server banners.
* [**PFPs.gg**](https://pfps.gg/) — Browse profile pictures and visual assets.
* [**PFPs.gg Banners**](https://pfps.gg/banners) — Explore banner designs for your profile.

{% hint style="warning" %}
**Design tip:** Use a cohesive color scheme, choose emojis that reflect your server's identity, and keep icons recognizable at smaller sizes. Consistent visual elements create a cleaner, more professional appearance.
{% endhint %}
